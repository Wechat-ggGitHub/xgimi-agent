# Privacy and security

Only source code, documentation and synthetic test fixtures belong in this repository. Never commit local settings, Keychain exports, access tokens, Codex conversation data, device addresses, wake captures, screenshots, audio recordings or research logs. Build output and runtime files are ignored; `.gitignore` does not replace review of staged files.

This project has no maintainer telemetry endpoint. External connections and local persistence are described in README.md. Only operate devices/accounts you own or have permission to control. Do not expose local device control ports to the Internet.

If a credential is exposed, revoke it first. Do not paste it into public issues. Use GitHub private vulnerability reporting when available; otherwise report a redacted description without the secret.
